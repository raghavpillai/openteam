# Use cases

Start with a task you can check: a report with sources, a cleaned file, or a draft to review. Once the result is useful, save the process as a skill or routine.

## Research a decision

> Compare three project-management tools for a five-person design studio. Use their current product and pricing pages, link your sources, and save a comparison with a recommendation and its tradeoffs.

Set up [web search](../configuration/web-search.md) first. Tell the bot your budget, requirements, and which sources matter. Ask it to separate facts from assumptions when information is missing.

## Turn files into useful work

> Use the attached support-ticket CSV to find our five most common issues. Include counts, show a few examples, and attach a summary plus a cleaned CSV. Keep the original file unchanged.

Attach the file in chat. Specify the output format and how you want ambiguous rows handled. See [files and results](../usage/files.md).

## Prepare for a meeting

> Review tomorrow's planning meeting and the project notes I linked. Prepare a brief with open decisions, overdue actions, and questions for each owner. Save it for me to review.

Connect the relevant calendar, notes, or meeting service through [plugins](../usage/plugins.md). Give the bot the right account and project rather than assuming it can find every source.

## Work on a codebase

> Review the checkout in /workspace/website. Find why the contact form loses its draft on navigation, propose a fix, then implement it and run the relevant checks. Leave the changes for review.

The bot works in its Linux environment. Make the repository available there, and explain how to run it. Access to a folder on your laptop requires the separate [local computer connection](../usage/computer.md#use-your-own-computer).

## Make a recurring briefing

> Every weekday at 9 AM in my time zone, summarize the new issues assigned to me. Group them by project, include links, and call out anything due this week.

First run the task once with a connected issue-tracker account. Check the result before creating a [routine](../usage/routines.md).
