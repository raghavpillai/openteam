---
description: Draft a PR description linking actual changes to meeting decisions.
---

Read [Granola workflow conventions](../OPENTEAM.md). Prepare a PR description for
$ARGUMENTS. Inspect the actual branch diff and any repository PR template. Find
the meeting decisions that explain the work and read their notes.

Lead with the concrete problem and resulting behavior. Explain which agreed
requirements the diff addresses, citing the meetings. Distinguish intentional
additions from recorded requirements and flag unresolved mismatches. Include
only checks actually run and their results; state untested behavior when it
matters. Match the repository template and scale the description to the change.
Drafting a description does not itself authorize committing, pushing, creating,
or updating a pull request.
