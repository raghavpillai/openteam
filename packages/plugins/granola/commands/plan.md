---
description: Turn meeting decisions into a prioritized implementation plan with sources.
---

Read [Granola workflow conventions](../OPENTEAM.md). Prepare a plan for
$ARGUMENTS using the user's current project and scope. Consult the installed
`granola-context` skill for the search workflow.

Find recent relevant meetings and read their notes. Extract agreed outcomes,
constraints, explicit owners, deadlines, dependencies, and unresolved questions.
Inspect the current project to identify work already completed. Distinguish
meeting priorities from priorities you recommend for technical reasons.

Produce an ordered plan. For each step give its intended outcome, concrete work,
dependencies, acceptance checks, and supporting meeting references. Keep unknown
owners and dates unknown. Separate required work from optional proposals and
show decisions that need resolution before implementation. Planning alone does
not authorize editing code or creating tasks in another service.
