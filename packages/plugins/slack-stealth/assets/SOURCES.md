# Slack plugin icon

**Slack:** Official multicolor icon from the navigation of the [Slack media kit](https://slack.com/media-kit), served at [Slack’s asset CDN](https://a.slack-edge.com/9cc0056/marketing/img/nav/logo.svg). Original 54 × 54 canvas, path geometry, and colors preserved.

Retrieved September 12, 2026. The original geometry and colors are preserved in `icon.svg`; `icon.png` is the 192-pixel raster version for desktop and native mobile. Bundled locally for offline display. The provider owns its trademark.
