# Xiaomi 一键运行 / 调试配置（2026-10-31）

目标：在 Android Studio 里点一次 Run / Debug，就自动构建 debug APK、安装到小米手机并拉起 `MainActivity`，不需要每次再选设备。

## 设备信息

| 项 | 值 |
| --- | --- |
| 型号 | Xiaomi M154FF（`ro.product.model=M154FF`，代号 `madrid`） |
| 系统 | Android 17（API 37，arm64-v8a） |
| 连接方式 | 无线调试（adb over Wi-Fi），adb serial 为 mDNS 名称，重连后可能变化 |
| 硬件序列号 | `a657db70` |

Android Studio 的设备标识使用硬件序列号（`serial=a657db70`），因此即使无线调试的 mDNS serial 变了，部署目标依然能匹配到这台手机。

## 已创建的配置

1. `.idea/runConfigurations/Xiaomi_Debug.xml`
   - 类型：Android App（`AndroidRunConfigurationType`）
   - 名称：`Xiaomi Debug`
   - 模块：`openteam-mobile.mobile.androidApp.main`（即 Gradle 的 `:mobile:androidApp` 的 `main` source set）
   - 启动方式：默认 Activity，部署 debug 包；Debug 按钮会用 Auto 调试器附加（Java/Kotlin）
   - 已带 `Android.Gradle.BeforeRunTask`，运行前会自动执行 Gradle 构建
2. `.idea/deploymentTargetSelector.xml`
   - 把 `Xiaomi Debug` 的部署目标固定为 `PhysicalDevice` / `serial=a657db70`
   - 选择模式为 `DROPDOWN`，所以点 Run 时不会再弹设备选择框

## 使用方法

1. 如果运行配置显示 `<no module>` 或 `Error: Module not specified`，先重启 Android Studio；然后在 Gradle 设置中选择 `GRADLE_LOCAL_JAVA_HOME`，执行一次 `Tools > Sync Project with Gradle Files`，等待 `:mobile:androidApp` 出现在模块列表中。
2. 在工具栏运行配置下拉框中选择 **Xiaomi Debug**。
3. 点 ▶ **Run** 运行，或点 🐞 **Debug** 调试。

运行后会自动：`assembleDebug` → 安装 → 拉起 `com.openteam.android/.MainActivity`。

## 前置条件（重要）

- **Gradle JDK must be 17–24.** The project now uses `GRADLE_LOCAL_JAVA_HOME` in `.idea/gradle.xml`, which reads the OpenJDK 21 path from `.gradle/config.properties`. This avoids Android Studio's bundled JBR 25, which cannot compile this Kotlin DSL project with Gradle 8.14.3:

  ```
  java.lang.IllegalArgumentException: 25.0.4
  ```

  If Android Studio reports that the Gradle JDK cannot be found, select `GRADLE_LOCAL_JAVA_HOME` again under `Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK`, or confirm that the path in `.gradle/config.properties` exists. OpenJDK 21 is installed through Homebrew on this machine.

  After running `./gradlew :mobile:androidApp:assembleDebug` with JDK 21, the APK is written to
  `apps/android/app/build/outputs/apk/debug/androidApp-debug.apk`。
- Android SDK 需包含 platform 36 / build-tools（`local.properties` 已指向 `~/Library/Android/sdk`）。

## 终端等价命令

不想开 IDE，或需要脚本化时：

```sh
# 构建 + 安装 + 启动（自动识别 M154FF，自动挑 17–24 的 JDK）
bash scripts/android/run-xiaomi.sh

# 启动后跟日志
bash scripts/android/run-xiaomi.sh --logcat

# 以“等待调试器”方式启动（am set-debug-app -w），再在 IDE 里 Attach
bash scripts/android/run-xiaomi.sh --debug

# 指定设备 / 指定 APK
bash scripts/android/run-xiaomi.sh --device <adb-serial>
bash scripts/android/run-xiaomi.sh --apk path/to/app-debug.apk
```

脚本会优先用 `--device`，其次 `ANDROID_SERIAL`，再按 `model:M154FF` 自动匹配，最后才退化为“唯一在线设备”。

## 排错

- **Run 配置里 Module 为空 / 提示未指定模块**：Gradle Sync 后模块名应为 `openteam-mobile.mobile.androidApp`。若不同，在配置的 Module 下拉里选一次 app 模块即可，之后会记住。
- **找不到设备**：`adb devices -l` 确认 `M154FF` 状态为 `device`；无线调试掉线时在开发者选项里重新配对。
- **改过运行配置名称**：`deploymentTargetSelector.xml` 里的 `runConfigName` 必须与运行配置名一致，否则目标设备会退回弹框选择。
- **JDK 25 报错**：见上文“前置条件”，切换 Gradle JDK 到 17/21。
