# Plugin icon

Apple's classic iMessage / Messages icon, downloaded from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:IMessage_logo.svg) on October 8, 2026. The source page credits Apple Inc. and the SVG author CMetalCore, and labels this version as used until September 14, 2025.

- Original SVG: https://upload.wikimedia.org/wikipedia/commons/5/51/IMessage_logo.svg
- PNG rendering: https://thumb.wikimedia.org/wikipedia/commons/thumb/5/51/IMessage_logo.svg/250px-IMessage_logo.svg.png

The original SVG is bundled unchanged as `icon.svg`. The PNG rendering is resized to 192 × 192 for desktop and native mobile display, preserving its colors and geometry. Wikimedia lists the artwork as PD-textlogo; Apple retains its trademark rights. Bundled locally for offline display.
