# Plugin icon

Official google-drive product icon from [Google’s product assets](https://www.gstatic.com/images/branding/productlogos/drive_2026/v2/web/192px.svg), linked by [Google Workspace](https://workspace.google.com/products/gmail/). Retrieved September 12, 2026. Original geometry and colors preserved; rasterized to 192 px for desktop and native mobile. Google owns the trademark. Bundled locally for offline display.

Rasterization note: the PNG uses white fills inside alpha masks, preserving the SVG's alpha-mask appearance in renderers that otherwise treat those masks as luminance. The original SVG is retained unchanged.
