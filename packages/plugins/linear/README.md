# Linear

Uses Linear's official MCP service with OpenTeam's existing browser OAuth setup.
The original [Linear Cursor plugin](https://github.com/linear/cursor-plugin/tree/dac1a08f4bd267b925460b5b8c1785f93248690b)
contains MCP configuration and metadata, with no skills.

The pinned revision has no declared redistribution license. Installation fetches
its unchanged files directly from GitHub using the revision and SHA-256 hashes
in `upstream.json`, then retains them in the installed snapshot. OpenTeam's
outer manifest supplies stable account identity and OAuth setup.
