# FCM operator verification

Run the credential-free payload checks with:

```sh
bash scripts/android/fcm-verify.sh payload
```

Validate the real-send configuration shape without printing values or contacting Firebase with:

```sh
bash scripts/android/fcm-verify.sh config
```

Real Firebase HTTP v1 delivery requires these environment variables in the worker process:

- `OPENTEAM_FCM_PROJECT_ID`
- `OPENTEAM_FCM_CLIENT_EMAIL`
- `OPENTEAM_FCM_PRIVATE_KEY`

The private key is a service-account PEM; escaped newlines are accepted. Credentials must remain in the deployment secret store. The operator command checks presence and shape only. It does not send a message, register a device, or print secret values.

The worker treats `UNREGISTERED` and equivalent invalid-device responses as terminal device retirement. Other FCM failures remain retryable through the existing outbox attempt schedule.
