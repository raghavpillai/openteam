---
description: Draft a reproducible bug report from a meeting or walkthrough.
---

Read [Granola workflow conventions](../OPENTEAM.md). Draft a bug report for
$ARGUMENTS. Find the referenced walkthrough or discussion and read its notes.
Use a transcript only when needed to establish the reported sequence.

Write a concrete title, expected behavior, observed behavior, environment,
reported reproduction steps, impact, and evidence. Preserve exact error text and
version information when present. Clearly label steps reported in the meeting
versus steps actually reproduced during this task. Do not invent missing steps,
severity, root cause, or a successful reproduction. Add focused questions for
missing information and links to the supporting meetings. Return or save the
draft as requested; creating an external issue is a separate requested action.
