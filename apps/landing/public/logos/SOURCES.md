# Provider logo sources

These are third-party trademarks used to identify supported model providers. The original path geometry and colors are preserved; ownership remains with the respective providers.

- **OpenAI:** `OpenAI-logos(new)/SVGs/OpenAI-black-wordmark.svg` from the official [2025 logo bundle](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip). [Brand guidelines](https://openai.com/brand/). Original 1604 × 718 canvas, including clear space, preserved.
- **Anthropic:** Inline header wordmark from the official [company page](https://www.anthropic.com/company). Original 570 × 64 viewBox and nine paths preserved. Generated CSS class removed; source comment added.
- **Google:** Inline header wordmark from the official [Brand Resource Center](https://about.google/brand-resource-center/brand-elements/). Original 74 × 24 viewBox, six paths, and brand colors preserved.

Retrieved September 12, 2026. SVG files are self-contained and served locally.

## Plugin logos

These trademarks identify the services shown in the interactive plugin demo. Retrieved September 12, 2026. Each SVG was checked to contain only vector geometry and local references, with no scripts or external resources.

- **Slack:** Official multicolor icon from the navigation of the [Slack media kit](https://slack.com/media-kit), served at [Slack’s asset CDN](https://a.slack-edge.com/9cc0056/marketing/img/nav/logo.svg). Original 54 × 54 canvas, path geometry, and colors preserved.
- **Linear:** Official Nordic Gray logomark embedded in the [Linear brand guidelines](https://linear.app/brand). Original 200 × 200 dimensions, 100 × 100 viewBox, path geometry, and #222326 color preserved.
- **Notion:** Cube mark from the official [Notion developer documentation](https://developers.notion.com/guides/get-started/overview), served in its [light header SVG](https://mintcdn.com/notion-demo/5YdhSbldE14t5Rna/logo/light.svg). Original cube path and black color preserved; accompanying “Developer Docs” text omitted and canvas set to 30 × 30 for the standalone mark.
- **GitHub:** Existing `GithubMark` path from `components/brand.tsx`, exported unchanged as a standalone 24 × 24 SVG with #24292f fill.
