# README artwork

`openteam-desktop-mobile.png` was refreshed on November 15, 2026 from
`db3607240` (the current `main` at capture time).

- Desktop: the production React `App`, rendered locally in light mode with
  fictional bots, a vendor comparison, and a weekday pricing routine. The bot
  details panel shows the Activity and Library tabs and computer preview.
- iPhone: the native SwiftUI app, built in Debug with Xcode 27.1 and captured
  in an iPhone 17 Pro simulator running iOS 26.5, using the same fictional
  conversation through a loopback-only fixture server.
- Computer preview: the existing `apps/landing/public/screenshots/linux-vendor-review.png`
  sample report capture; it is not a newly executed comparison.

The captures replace the screens within the original transparent MacBook and
iPhone artwork. Device frames and composition are retained; native Mac window
controls and space for the display notch are added when framing the desktop
renderer. No real accounts, model calls, or scheduled tasks were used.
