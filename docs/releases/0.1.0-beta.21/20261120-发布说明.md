## 中文

OutcomeGo `0.1.0-beta.21` 同步了服务端、CLI、桌面端、Android 和 iOS 源码的版本信息。

- 桌面端和 Android 可把新目标或记录的想法直接交给机器人。目标拥有独立的规划与审阅对话，支持进度更新、结果简报、验收和返工。iOS 增加了目标创建和对话入口。目标管理默认关闭，可在桌面设置的「常规」中启用。
- 桌面端新增机器人浮窗，可查看未读消息和待批准目标、快速发消息。在 macOS 上可将附件拖入浮窗，并可在「键盘」设置中自定义快捷键。
- Android 增加目标工作台、手势反馈，以及无 FCM 时可用的前台同步通知。Android 和 iOS 均支持群聊免打扰和目标通知卡片。
- 远程 MCP 插件可以轮询事件并触发机器人例程，包括 Codingns4DSH 会话事件。更新还改进了目标运行恢复和备份校验。
- 提供 macOS、Linux、Windows 桌面包及已签名的 Android APK。Windows 安装包和 Linux AppImage 未签名。本次 iOS TestFlight 分发已停用。移动端真机验收仍需单独完成。

### 安装服务端

```sh
curl -fsSL https://github.com/jingyi0605/OutcomeGo/releases/download/v0.1.0-beta.21/install.sh | sh
```

```powershell
irm https://github.com/jingyi0605/OutcomeGo/releases/download/v0.1.0-beta.21/install.ps1 | iex
```

签名的 Compose 文件固定四个服务镜像的 digest。内容未变的镜像可复用既有 digest，并保留原有 OCI 版本和修订标签。此版本的 CLI 下载使用 `outcomego-*` 文件名，本地 `aiteamos` 命令仍兼容。

## English

OutcomeGo `0.1.0-beta.21` synchronizes release metadata for the server, CLI, desktop, Android, and iOS source.

- Desktop and Android users can send a new goal or a saved idea directly to a bot. Each Outcome has its own planning and review conversation, with progress updates, a results brief, acceptance, and rework. iOS adds goal creation and conversation entry points. Outcome management is off by default and can be enabled under General in desktop settings.
- A floating bot window shows unread messages and goals awaiting approval, and lets you send a quick message. On macOS it accepts dropped attachments. Its shortcuts are configurable in Keyboard settings.
- Android adds an Outcomes dashboard, gesture feedback, and foreground message sync for notifications without FCM. Android and iOS support group chat muting and Outcome notification cards.
- Remote MCP plugins can poll for events and trigger bot routines, including Codingns4DSH session events. This release also improves Outcome recovery and backup verification.
- The release includes macOS, Linux, and Windows desktop packages and a signed Android APK. The Windows installer and Linux AppImage are unsigned. iOS TestFlight distribution is disabled. Physical-device acceptance remains pending.

### Install the server

```sh
curl -fsSL https://github.com/jingyi0605/OutcomeGo/releases/download/v0.1.0-beta.21/install.sh | sh
```

```powershell
irm https://github.com/jingyi0605/OutcomeGo/releases/download/v0.1.0-beta.21/install.ps1 | iex
```

The signed Compose file pins all four server image digests. Unchanged images can reuse an existing digest and retain their original OCI version and revision labels. CLI downloads use `outcomego-*` filenames, and the local `aiteamos` command remains compatible.
